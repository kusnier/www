Kleine Dateien. Ganz ohne Upload.

Diese erste Version überträgt bis zu 2 KiB Nutzdaten in einem einzelnen Code. Die zusätzliche Dateihülle benötigt ebenfalls Platz. Größere Dateien und Bildfolgen mit mehreren Codes sind hier noch nicht unterstützt.

Alle Eingaben und Bilder werden auf deinem Gerät verarbeitet und nicht gespeichert oder versendet. Ein JAB-Code ist keine Verschlüsselung: Wer das Bild besitzt, kann den Inhalt mit einem passenden Decoder lesen. Gewöhnliche QR-Scanner unterstützen JAB-Codes nicht unbedingt.
